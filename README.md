# Universal Website Builder v3.0 — Industry-Aware AI Design Prototype

This is a static GitHub Pages prototype. No external images are used.

## What changed from v0.2
- Business DNA profile: business type, audience, goal, personality, content density.
- 12 business/industry packs instead of a small generic theme list.
- Each pack recommends 6 genuinely different design directions.
- Design directions change layout language, typography, color palette, conversion flow, motion language and content emphasis — not only accent color.
- AI-era experience layer: AI Product Finder, Conversational RFQ, Smart Search, Personalized Showcase, Digital Showroom and AI Content Studio.
- Live preview with desktop/tablet/mobile controls.
- Generated design-system panel with palette, typography, motion and conversion strategy.
- Preview uses CSS-generated visual structure; no external image dependency.

## Industry packs
Manufacturing/OEM, Saddlery & Equestrian, Leather Manufacturing, IT/Technology, Furniture/Interior, Restaurant/Hospitality, Fashion/Luxury Goods, Healthcare, Education, Real Estate, Construction/Infrastructure, Professional/B2B Services.

## Important
This is still a front-end prototype. It does not yet save projects to MariaDB, generate real AI content, import real product databases, or publish to customer hosting. Those are the next engineering stage after the design system is approved.

## GitHub Pages
Open `builder-demo/index.html` through GitHub Pages. The preview uses `shifa-demo/theme.html?theme=...` and works without a server.
